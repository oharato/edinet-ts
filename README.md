# edinet-ts

EDINETのXBRLから財務数値を読み取り、**前年より利益率や収益性が伸びた企業を高速にスクリーニング・抽出**するための軽量TypeScriptライブラリ＆CLIです。

保存先・検索エンジンには **DuckDB** を採用しており、大量の決算書データを高速にSQL絞り込み・ソートできます。

---

## 主な機能

- **高精度な財務抽出**:
  - 日本基準（J-GAAP）および国際財務報告基準（IFRS）に対応
  - 連結決算を優先抽出し、なければ単体決算を採用
  - 1つの有報から**当期と前期の数値を自動突合**
- **豊富な投資・財務指標の自動計算**:
  - **稼ぐ力**: 営業利益率、利益率前年比成長率、売上高・営業利益成長率
  - **キャッシュ創出力**: フリーキャッシュフロー（FCF = 営業CF + 投資CF）、営業CF
  - **資本効率・健全性**: ROE（自己資本利益率）、ROA（総資産利益率）、自己資本比率
  - **労働生産性・株主還元**: 従業員1人当たり営業利益、1株配当金（DPS）、配当成長率、EPS、BPS
- **DuckDB による高速スクリーニング**:
  - インメモリまたはファイルベースのDuckDBに一括ロード
  - 「利益率成長率 >= 20%」「ROE >= 15%」「フリーCFが黒字」などをSQLで瞬時に抽出
  - `--where "<SQL条件>"` で自由自在にフィルタリング可能
- **人間にもAIにもフレンドリーな自己案内**:
  - `edinet-ts schema` で利用可能な全カラム・型・単位・クエリレシピを表示
  - `edinet-ts schema --json` でAI向け構造化スキーマを出力

手元にある `archive.sqlite`（約3,700社分の有報原本）から DuckDB へ高速インポートできます。

```bash
# テスト用（100社）

# 全件インポート（約3,700社）
node dist/cli.js import-archive --db ./data/screening.duckdb
```

```bash
  --where "operating_margin_current >= 0.15 AND equity_ratio_current >= 0.60 AND operating_margin_growth_rate > 0"
```


### 5. EDINETから最新の有価証券報告書を差分同期する (`sync`)

手元のDuckDBを最新の状態に維持するために、EDINET API v2から最近開示された有価証券報告書（有報: docTypeCode 120）を自動取得し、差分更新します。

```bash
# 直近7日分の有報を差分同期（デフォルト）
node dist/cli.js sync --db ./data/screening.duckdb

# 直近30日分の有報を同期
node dist/cli.js sync --days 30 --db ./data/screening.duckdb

# 期間を明示指定して同期
node dist/cli.js sync --since 2026-03-01 --until 2026-03-31 --db ./data/screening.duckdb

# ダウンロードやDB更新を行わずに、対象書類の一覧と件数のみ確認 (Dry Run)
node dist/cli.js sync --days 14 --dry-run
```

- **自動重複スキップ**: 既にDuckDB内に存在する企業・決算期データは自動的にスキップされるため、重複登録されません。
- **ローカルキャッシュ**: 取得したXBRLは `data/edinet-cache/` に保存され、不要な再通信を防止します。
- **環境変数**: `EDINET_API_KEY` を設定しておくと、`--api-key` オプションの入力を省略できます。
