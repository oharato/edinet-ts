# 確認した負債構成を使うROIC

`calculateRoic({ income, opening, closing })` は、年次営業利益・税引前利益・法人税等と期首/期末の株主資本・明示負債から `effectiveTaxOperatingIncomeToAverageDeclaredCapital` を計算します。

算式は **営業利益 × (1 − 法人税等 / 税引前利益) ÷ 平均（株主資本 ＋ 確認した有利子負債）** です。[NRIの用語解説](https://www.nri.com/jp/knowledge/glossary/roic.html)を参考に、このAPIの定義を固定しています。現預金を控除せず、評価・換算差額等や非支配株主持分を株主資本に加えません。企業が公表するROICは定義が異なる場合があるため、公表値との一致は保証しません。

## 原本と確認宣言

`income` は `{ xml, metadata }`、`opening` と `closing` はそれに `capitalDeclaration` を加えます。metadataは既存の財務明細形式です。J-GAAP/JPY、同じ会社・entity・scope、連続12暦月のannual期間、その開始前日と終了日の残高を要求します。

```ts
const capitalDeclaration = {
  state: "confirmed" as const,
  debtMetricIds: ["shortTermLoansPayable", "longTermLoansPayable"] as const,
  proof: {
    key: "jpcrp_cor:ConsolidatedBalanceSheetTextBlock" as const,
    contextRef: "CurrentYearDuration",
    rawSha256: "原本の該当fact.rawValueをSHA-256にした64桁の16進文字列",
  },
};
```

利用者が貸借対照表と借入金・社債明細等を読み、**有利子負債の全構成を重複なく指定**します。短期借入金が一年内返済予定の長期借入金を含む場合、その内訳を再加算しません。期首と期末で構成が変わる場合は別々に宣言できます。負債なしの確認は空配列で明示します。

対応IDは `ROIC_DEBT_METRICS` の9科目（短期/長期借入金、一年内返済予定長期借入金、一年内償還予定社債、社債、流動/固定リース債務、CP、短期社債）です。必要な負債をこれらの直接factで表せない場合は計算できません。

`proof` は連結/個別に合う貸借対照表text blockのQName・context・`fact.rawValue`（既存parserによるXML復号・外側空白除去後）のhashです。原XML全体のbyte hashも別に保持します。APIは同じ原本に一意に存在する参照、公式名前空間、entity・scope・日付を検査します。**参照の存在確認は、科目集合の完全性や利用者の読解を認証するものではありません。** 計算結果にも `declaration: "source-reviewed-by-caller"` を残します。未確認は `{ state: "unknown" }` とし、理由 `unverified-capital-definition` で計算を停止します。

## 計算と検索の境界

- 欠損・nil・曖昧な選択を0にしません。固定税率や期末だけの資本で代用しません。全選択結果とXML hash、宣言を返します。
- 税引前利益は正、実績税率は0〜1、負債は非負、期首/期末資本はそれぞれ正であることが必要です。営業赤字・税率0/1は保持します。
- 営業利益だけは完全一致重複を明示採用し、その証跡を残します。その他の明細は既存の選択規則を使います。
- `value` は近似表示用の比率（1=100%）、`exact` と各中間値は開示入力からの正確な分数です。開示の丸め精度を超える正確さは示しません。
- `screenRoic(inputs, { conditions, order, offset, limit })` は同一期間・残高日・範囲・基準・通貨の企業集合を比較します。比較/並び順は正確な分数を使い、計算不可と条件不一致を別件数で返します。会社重複と別会社の同一書類IDを拒否します。
- 検索は最大100社・原本合計256MiB、各XMLは既存の64MiB上限です。IFRS/US-GAAP、金融業特例、訂正全文の合成、SQL保存/CLIは未対応です。

## 取得済み原本による確認

ミライト・ワン `S100VZQA`、2024-04-01〜2025-03-31の連結原本を使用。PDF88ページの貸借対照表、89〜90ページの損益、87ページの返済予定、131ページの社債/借入金等明細を照合しました。

| 入力 | 金額（百万円） |
|---|---:|
| 営業利益 / 税引前利益 / 法人税等 | 27,985 / 27,961 / 10,085 |
| 期首資本 | 239,832 + 75,148 + 31,003 + 3,539 + 7,402 = 356,924 |
| 期末資本 | 245,748 + 42,596 + 40,495 + 30,000 + 4,463 + 9,937 = 373,239 |

短期借入金のBS金額には一年内返済予定長期借入金が含まれます。明細は切捨てのため、75,001+146とBS75,148等は一致しません。BSの直接値を採り、内訳を足し直しません。期首社債なしは社債明細の記載を確認した宣言であり、nilの自動0変換ではありません。正確な計算比率は `1000519720/20416087643`（約4.90064%）。この例だけで全市場の負債定義を確認したとは扱いません。
