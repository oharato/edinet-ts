# 外部補完データの採否（2026-10-28）

外部データを使う目的、採否、確認が必要な条件をまとめています。データを取得できることと、保存・再配布・運用へ利用できることを分けて判断します。

利用者の「無償・既存データを優先」に従います。データの有用性だけでなく、観測時点・保存/再配布条件・認証・継続費用を採否に含めます。以下は段階10の候補選定であり、外部APIやAI分析の実装完了を意味しません。契約/登録・課金・新しい認証の取得は実行していません。

| 領域 | 今回の判断 | 実装へ渡す条件と残り |
|---|---|---|
| 価格 | 既存ローカルキャッシュの明示入力を採用 | close・出来高・取得/利用可能時点・古さ・元hashを保持。調整後価格から分割履歴を推測しない。既存ファイルを読めることは、そのデータの外部配信許諾を意味しない。新規価格取得元の採用はまだしない |
| 価格/分割の追加取得 | J-Quants Freeを共通サーバーの既定取得元には不採用 | 無料でも直近価格の用途と、永続原本保存/共通データ配信の要件に合わない。利用者自身の私的環境で条件を満たす場合の個別入力は別設計。Pro等の契約へ自動移行しない |
| 法人情報 | まず既存EDINETマスターと原本内法人番号を採用。国税庁ファイルを追加候補にする | 国税庁の最新一括ファイルを過去年の企業属性に遡及適用しない。取得日・対象日・変更履歴が必要。名称の一致だけでは関係会社/顧客へ法人IDを付けない。全国一括取得は未実行 |
| 不動産 | 既存設備開示の原表を優先。地価による自動時価評価は現時点で不採用 | 不動産情報ライブラリには無償APIがあるが申請が必要。事業所の所在地だけで地番・所有範囲・利用権を特定できず、近傍地価×面積を保有物件の時価に置換しない。将来の参考地点表示と資産評価は別モデル |
| IR/PDF | 保存済み公開資料の出典付き抽出を採用 | 原文/URL/書類hash/ページ/観測日時を残す。会社予想・計画・実績を分離。本文の推測値を直接XBRL値へ混ぜない。新規大量クロールは不要 |
| 短信/業績予想 | 保存済み資料を入力する方針。取得先選定とデータモデルは継続 | 予想修正時点・対象期間・連結/単体・会社予想/外部予想の区分を設計する。EDINET有報の実績を速報値や会社予想と呼ばない |
| AI分析 | 現時点では外部有料AIを既定採用しない | 既存資料から根拠付き入力を作り、生成物を構造化原値と別に扱う。モデル/ライセンス/入力取扱い/費用を確定できていないため、AI実行・モデルの自動取得は未実施。ローカル/無償候補も検証なしに品質保証しない |

## 判断に使った一次資料

J-Quantsの[プラン説明](https://jpx-jquants.com/ja/help/plan)ではFreeのデータに12週間の遅延があり、[利用目的・ライセンス](https://jpx-jquants.com/ja/help/usage)では個人の私的利用への限定、共通サーバーでの蓄積/中継や第三者公開の条件、解約後の保存データ削除が説明されています。このため本プロジェクトの共通・継続保存向け既定データ源にはしない、という実装上の判断です。

調整後株価が過去へ再計算されることも[データ仕様FAQ](https://jpx-jquants.com/ja/help/data)に記載されており、取得日時の異なるadjusted値だけから企業行動の発生日や倍率を確定しません。

国税庁の[全件データ案内](https://www.houjin-bangou.nta.go.jp/download/zenken/)は前月末の最新情報と差分取得の継続方法を説明しています。APIキーを流用せず、必要な場合はこのファイル形式と履歴を検証します。保存/再配布の詳細条件は採用時に対象ファイルの条件も確認します。

国土交通省の[API操作説明](https://www.reinfolib.mlit.go.jp/help/apiManual/)には事前申請が必要とあり、[利用規約](https://www.reinfolib.mlit.go.jp/help/termsOfUse/)には無償利用と情報ごとの条件があります。無料であることと、開示された事業所を個々の土地へ正確に結び付けられることは別です。

## 継続工程

既存価格とEPS/BPS/DPSの株式基準・実績/予想区分を一致させる評価指標、原表からの設備/顧客等の領域別モデル、企業履歴と法人ID照合、予想の時点管理、AI出力の根拠/検証を引き続き実装します。本判断でこれらを完了扱いにしたり、全体ロードマップから削除したりしません。
