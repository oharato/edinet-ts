## 現在の変更単位

1. 税引前利益だけ完全一致重複を理由付きで採用し、旧JSONの曖昧判定を保持（registry 4→5）。
2. 法人税等支払額・配当金支払額・長期借入金返済を直接3項目として追加（registry 5→6）。既定5項目・主要18/21指標・既存SQLite形式は維持。
3. 2を含む回帰と実原本検証後、未完了段階へ進む。直近変更だけで全体の完了とはしない。

型/テスト/原本照合の結果は、それぞれ実行完了後に記録します。以前の「確認待ち」は上記範囲の承認で解消済みです。
