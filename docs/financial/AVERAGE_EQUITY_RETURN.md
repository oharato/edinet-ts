# 平均自己資本を使う計算ROE

年次利益を、期首と期末の自己資本の平均で割ってROEを求めます。原本に掲載されたROEを読むAPIとは計算の入口が異なります。

`calculateAverageEquityReturn({ income, opening, closing })`は、明示した年次利益原本と期首/期末残高原本から`netIncomeToAverageEquity`を計算します。掲載値の`rateOfReturnOnEquity`は維持します。

算式は親会社株主に帰属する当期純利益 ÷〔期首自己資本と期末自己資本の平均〕、このAPIの自己資本はJ-GAAPの直接科目「株主資本＋評価・換算差額等（連結のその他の包括利益累計額）」です。株式引受権・新株予約権・非支配株主持分を含む純資産全体とは区別します。

自己資本と平均残高によるROEの定義は[JPX用語集](https://www.jpx.co.jp/glossary/sa/549.html)を参照してください。

- J-GAAP/JPY、同じ会社・entity・scope、連続12暦月のannual分類と、その開始前日/終了日の残高が必要です。期間や基準を推測しません。
- 利益と2時点×2科目の原値・選択理由・証跡・XML hashを返します。金額の開示精度を超える正確さを保証しません。
- 評価差額の負値や損失は保持します。平均自己資本が0以下なら計算不可です。片方の自己資本が負でも、平均が正なら計算します。
- 比率の`value`は近似表示用（1=100%）。`exact`、`openingEquity`、`closingEquity`は開示された入力からの正確な分数です。
- 構成科目の欠損は0にしません。純資産や期末だけの残高で代用しません。IFRS/US-GAAPや52週決算は未対応です。

## 利益の一致重複を明示採用

この新規計算だけは、利益の候補が同じQName/名前空間URI・raw・精度・単位・期間/scope・entity・次元で完全一致するとき、理由`selected-identical-duplicates`付きで採用します。金額違い・精度違い・nil混在等は採用しません。

全出現のevidenceを残します。完全一致と単なる数値整合の区別は[XBRLの重複factの指針](https://www.xbrl.org/WGN/xbrl-duplicates/WGN-2025-01-14/xbrl-duplicates-2025-01-14.html)に沿います。

この方針は`object.selectMetric(id, options, { collapseIdenticalDuplicates: true })`で明示利用できます。省略/falseでは既存どおり重複を拒否します。

既存CAGR・前年比・平均総資産利益率の既定方針や、古いJSONの判定は昇格させません。直接財務明細は別途、完全一致重複の採用と旧JSON互換に対応しています。自己資本の構成2科目も直接明細の規則で完全一致重複を扱います。異値・精度差などのある構成値は採用しません。旧18指標の `selectMetric` は明示オプションを省略すれば重複を拒否します。

## 同じ条件の企業集合で比較

`screenAverageEquityReturn(inputs, { conditions, order, offset, limit })`で、同じ利益期間・残高時点・scope・基準・通貨の企業を比べます。条件は`{ operator: "gte", value: 0.08 }`等です。

比較と順序は表示近似値ではなく分数を使います。会社の重複や異なる企業での同じ書類IDは条件で隠さず拒否します。

計算不可と条件不一致は別件数です。
